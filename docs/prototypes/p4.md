# Prototype 4 — One feature issue to a tested code pull request

## Scope

The Implementation Agent implements one approved feature issue under `src/` and `tests/`. Tests run in the session Vercel Sandbox with `networkPolicy: "deny-all"` and an allowlisted `node --test` command. A pull request is opened only when that command exits 0. The agent never merges and never deploys.

No approved issue plan exists yet. The fixture `fixtures/test/p4-feature/` is a tiny title normalizer, not Task Tracker Lite. The unit test executes that fixture locally with `node --test`. The agent tool calls `sandbox.run` with the same allowlist. A live sandbox session was not started.

## Acceptance criteria

- The fixture test command exits 0.
- A failing exit code blocks the pull request.
- Commands that deploy, push, or use curl are rejected.
- A fixture cannot open a project pull request.
- `docs/tor.md` cannot be committed.
