# Prototype 5 — Implementation feedback to an approved specification update

## Scope

The Change Control Agent classifies feedback as an elaboration or a contradiction with the frozen TOR. A contradiction is rejected and the TOR file is not a commit candidate. An accepted elaboration revises the SRS without dropping existing requirement ids. A person approves the change in a pull request. The agent never merges.

No live implementation feedback exists. Tests use `fixtures/test/p5-change/` plus the real frozen TOR only as the hash baseline, not as a rewritten document.

## Acceptance criteria

- Rejecting a request for external customer access passes.
- Accepting that contradiction fails.
- An elaboration that keeps every `FR` and `NFR` id passes.
- A revised SRS that adds external customer access, or drops an id, fails.
- A fixture cannot open a project pull request.
