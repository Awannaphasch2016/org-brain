# Map the TOR analysis

Read `docs/tor-analysis.md` that came with the approved TOR. Use its extraction and field statuses to fill the SRS sections. Do not open the TOR to extract it again. Do not write `docs/_analysis.md` or any new TOR extraction.

Carry each confirmed field into the matching SRS section. Leave an unconfirmed field out of the requirement text and record it as a gap instead.
