# Implement one issue

Read the issue acceptance statement. Write the smallest code and tests that satisfy it. Keep the change inside that issue.

Run `node --test` through `run_tests`. Do not use the shell to deploy, push, or reach the network. Open a pull request only when tests pass and the input is not a fixture.
